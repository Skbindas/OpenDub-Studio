    Processing location · Local / Kaggle

    Local processing is available. Kaggle processing is experimental. A short-video cloud test passed technical checks; full-movie and GPU-withdrawal tests are not certified. GPU availability and quota depend on your account. Switching back to local stops this app's cloud monitoring; it does not cancel a notebook already queued/running on Kaggle.

    Private personal research usage only. Some accelerators require special access. Selecting a GPU does not prove it is available.

    Secure API credentials

    Saved in your OS credential vault. No keys are returned to the browser or stored in browser storage. Run scripts/setup_kaggle.py with the app's Python first; it creates an isolated SDK environment. Enter credentials here yourself.
