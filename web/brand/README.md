# OpenDub Studio brand pack

The built-in ImageGen tool produced the two raster originals. Its exact model version was not exposed. Full prompts are in [PROVENANCE.json](PROVENANCE.json). Elnavix's asset workflow was a read-only reference; no Elnavix logo or product artwork was copied.

| Asset | Format / intended use |
|---|---|
| `symbol-ai-v1.png` | Native1254×1254 RGBA output, genuine alpha preserved; visual source/reference |
| `cover-ai-v1.png` | Native1774×887 RGB output; supporting concept illustration, not a UI screenshot |
| `opendub-mark-v2.svg` | Editable geometric adaptation for the application header and favicon |
| `opendub-mono.svg` | Single-color adaptation with transparent negative space |
| `opendub-wordmark-v2.svg` | Editable wordmark; system-font text may differ across machines |
| `icons/*.svg` | Seven original vector workflow icons: upload, languages, voices, timeline, preview, export, setup |
| `review.html` | Local comparison, small-size render checks and downloads |

Canonical vector colors: blue `#2455C8`, teal `#19B596`, ink `#182D42`, white background. Raw generated pixels retain their original colors and alpha. The SVGs are simplified adaptations, not exact traces or native vector model output. The earlier v1 SVGs are retained.

Keep clear space around the mark and use the SVG at small UI sizes. The source PNG is intentionally not loaded into the main application header. This pack does not include a trademark clearance, an outlined font wordmark, or public media/voice permissions.
