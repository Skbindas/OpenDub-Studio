# OpenDub Studio v0.1.0-alpha.1

First experimental source-only prerelease. Application code is MIT; optional model weights, services and user media have separate terms.

## Included
- Local browser studio with saved projects and resumable stage work.
- Speaker/character review, audition and explicit approval gates.
- Private own-recording intake with exact transcript and original preview.
- Local prerequisite checklist and optional personal Kaggle processing.
- Clone/install and local/Kaggle guides; open contribution/review workflow.
- Original blue/teal artwork, editable SVG variants and provenance.

## Validation
Clean source passed468 Python tests (2 skipped,1 feature-length deselected) and14 frontend tests. Fresh core environment served five UI/API endpoints without private voices or copied packages. GitHub release notes identify exact commit/CI.

## Limits
No movie recordings/catalog, model weights, media binaries or public voice pack are bundled. Full optional-model clean installation, full movies, all language pairs/GPUs, overlap repair and live GPU-replacement acceptance remain unverified. Human listening and speaker review are required. Current OmniVoice weights have non-commercial terms.

The public before/after pair awaits an owner-supplied permission-cleared recording. No sample or full-movie completion time is promised.

Start with docs/INSTALL.md, docs/LOCAL_SETUP.md or docs/KAGGLE_SETUP.md. See docs/RELEASE_READINESS.md for scope. Contributions are welcome under CONTRIBUTING.md; PRs are reviewed before merge.
