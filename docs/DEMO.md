# Samples and media policy

The source repository and published source archive contain no user recordings, rendered demo videos, private transcripts, voice-reference recordings, training datasets or model weights. Original brand illustrations are conceptual artwork, not user-media examples.

Automated test files exercise software behavior. Do not add private recordings, transcript excerpts, voice references, generated exports, consent records, credentials or local paths to source control, issues or pull requests.

Use media and voice references only when you own them or have permission to process them. Keep inputs and exports in the local runtime, which is excluded from Git. Any future public demo requires separate permission, privacy review, listening review and explicit maintainer approval before publication.
