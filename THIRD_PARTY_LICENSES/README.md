# Third-party components and model licenses

OpenDub Studio is an orchestration/application layer. It may use external libraries, model code, model weights and binaries.

Before redistribution or commercial deployment, verify the license for:
- the upstream repository/code
- pretrained model weights
- downloaded voice packs
- FFmpeg builds and codecs
- datasets or reference audio used for model development

Do not assume that an open-source GitHub repository automatically makes every model weight or asset commercially redistributable.

Each integrated engine should have a corresponding entry here before it becomes a bundled/default component.
